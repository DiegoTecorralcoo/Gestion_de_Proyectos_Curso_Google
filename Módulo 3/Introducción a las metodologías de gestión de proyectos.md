# Metodologías de gestión de proyectos: Lineal vs Iterativo
*Notas tomadas por Diego Salvador Tecorralco Martinez*


## ¿Qué es una metodología de gestión de proyectos?

- Conjunto de **principios y procesos rectores** para gestionar un proyecto a lo largo de su ciclo de vida.
- Ayudan a guiar al PM con:
  - Pasos a seguir.
  - Tareas a completar.
  - Principios para administrar el proyecto.


## Dos enfoques principales: Lineal e Iterativo

### Enfoque Lineal

**Características:**

- Cada fase o tarea debe completarse **antes** de que comience la siguiente.
- Proceso **secuencial** y ordenado.
- Poco espacio para cambios una vez iniciado.

**Ejemplo: Construcción de una casa**

- Necesitas el **plano** antes de sentar los cimientos.
- Terminar los cimientos antes de colocar las paredes.
- Paredes antes del techo.
- El objetivo es **claro** y fijo: sabes exactamente cómo será el resultado final.
- No se pueden hacer cambios a medio camino (ej: pasar de bungalow a victoriano de varios niveles).

**Cuándo usarlo:**

- Proyectos que no requieren muchos cambios durante el desarrollo.
- Cuando hay un proceso claro y definido desde el inicio.


### Enfoque Iterativo

**Características:**

- Mayor **flexibilidad**.
- Se anticipan **cambios**.
- Algunas fases o tareas pueden **superponerse** o hacerse al mismo tiempo.
- Se pueden probar partes del proyecto antes del resultado final.
- Se puede entregar **partes del proyecto** a medida que se completan.

**Ejemplo: Producción de un programa de TV**

- Se filma un **piloto** y se prueba en diferentes lugares y horarios.
- Se recogen **comentarios** y se hacen ajustes.
- Mientras se trabaja en la versión final, se puede:
  - Contratar actores permanentes.
  - Iniciar producción cinematográfica.
  - Trabajar en publicidad.
- El resultado final puede ser **diferente** al original (ej: de 1 hora a 30 minutos, o un personaje secundario se vuelve principal).

**Cuándo usarlo:**

- Proyectos donde los requisitos pueden cambiar.
- Cuando la retroalimentación continua es importante.
- Proyectos que se benefician de pruebas y ajustes constantes.


## Comparación rápida

| Lineal | Iterativo |
|--------|-----------|
| Secuencial | Flexible |
| Poco cambio | Anticipa cambios |
| Resultado fijo | Resultado puede evolucionar |
| Entrega al final | Entregas parciales posibles |
| Ej: construcción | Ej: desarrollo de software, TV |


## ¿Cómo trabaja Google?

- Enfoque **híbrido**.
- Mezclan y combinan métodos según el tipo de proyecto.
- Se anima a los PM a **adaptar su propio estilo** a lo que tenga más sentido para su proyecto y equipo.


## Conclusión

- No todos los proyectos son iguales.
- Cada enfoque beneficia a diferentes tipos de proyectos.
- Pronto aprenderás a elegir o combinar enfoques para cada situación.
